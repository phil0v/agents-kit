# Antigravity dispatch

Antigravity resolves profiles with `role-profile.py --harness antigravity --role <role>` (and optional `--provider <id>` for a local provider table). The committed roles use `model: "runtime-default"` and `effort_policy: "unsupported"` (`effort: null`), with native tools `read_file`, `write_file`, `edit_file`, `grep_search`, `find_by_name`, and `run_command`. Generated forms in the `agy-agents` package under `agents/<role>.md` register six native subagents (`worker`, `reviewer`, `style-reviewer`, `plan-reviewer`, `spec-reviewer`, `tool-runner`). Each form sets `model: "inherit"`, `subagent: true`, `mainAgent: false`, and `commandExecutionPolicy: "sandbox"`, omits the effort key, and declares a YAML `tools` array. Select the matching `<role>` subagent via `invoke_subagent` only if loaded-profile evidence confirms a match with the resolved profile. The evidence must cover the subagent model, the tools, and the complete canonical body. Verify actual tool grants from runtime launch or registry metadata. A generated file, a plugin listing, or a self-reported name alone is not enough. When no model or effort is requested, use the runtime default and omit model and effort API arguments. Requested model/effort handling and `--provider <id>` overrides that resolve a concrete model follow Capability preflight and Effective profiles in `<package>/references/dispatch.md`.
